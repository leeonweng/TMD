## 🎮 互動式小遊戲特色（投石戰車拋物線攻城挑戰）

依照教案中活動二「數位線索實驗室」與活動四「彈性極限試煉」所設計之高互動物理小遊戲：
1. **多重物理變因控制**：
   - **拋射角度（θ）**：自訂 10°~85°，並設有教案核心角度快捷鍵（30°、45° 最佳射程、50°、65°、80°）。
   - **橡皮筋彈力**：細橡皮筋 (18 m/s)、標準橡皮筋 (26 m/s)、粗橡皮筋 (36 m/s)。
   - **拋射物材質**：乒乓球（輕，受空氣阻力大）、黏土球（標準）、彈珠（重，穿透力強）。
2. **雙遊玩模式**：
   - **🎯 攻城打靶挑戰**：隨機距離與高度城垛目標，測試學生角度與初速推算能力。
   - **🔬 自由探究實驗室**：保留多色發射軌跡，即時記錄飛行時間、最高點高度與拋射距離。
3. **數據表格即時連動**：
   - 每次發射結果自動匯入「測試數據記錄表」，直接支援活動五之折線圖與數據統計分析。
4. **原生合成音效**：使用 Web Audio API 生成射擊風聲與命中爆破音效，無須下載外部檔案。
